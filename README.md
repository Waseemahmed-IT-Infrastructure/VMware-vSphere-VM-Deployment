
# VMware vSphere - Virtual Machine Deployment

## Overview

This repository covers virtual machine deployment and management using VMware vSphere and vCenter.

My work includes creating Windows Server virtual machines, assigning resources, installing operating systems and managing virtual machines.

## VM Deployment

The main steps I follow when creating a virtual machine are:

1. Log in to VMware vCenter.
2. Select the required ESXi host or cluster.
3. Create a new virtual machine.
4. Select the datastore.
5. Choose the operating system and compatibility settings.
6. Assign CPU, RAM and disk space.
7. Configure the required network.
8. Attach the Windows Server ISO.
9. Power on the VM and install Windows Server.
10. Install VMware Tools and check the VM status.

## VM Management

- Adjusting CPU, RAM and disk resources
- Checking VM performance and alerts
- Managing VM power operations
- Working with datastores and clusters
- Checking VMware Tools status
- Troubleshooting basic VM issues
